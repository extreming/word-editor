# Docflow 产品手册

产品名称：Docflow  
版本 `1.0.0`  
编写日期：2026 年 9 月 2 日

## 1. 产品简介

Docflow 是一款可独立部署、可嵌入业务系统的浏览器文档编辑器。用户可以打开 Word 文档，进行文字排版、表格编辑、批注和修订，再导出文件或保存回业务系统。

产品主要适用于合同修改、文档审阅、日常文字处理，以及业务系统内的文档预览与编辑。PDF 使用独立的查看与标注界面。

### 1.1 核心能力

| 能力       | 说明                                                           |
| ---------- | -------------------------------------------------------------- |
| 文档编辑   | 编辑正文、标题、列表、表格、图片和超链接                       |
| 页面排版   | 设置纸张、方向、页边距、分页、页眉、页脚和页码                 |
| 文档审阅   | 添加批注、回复、处理批注，以及记录、接受或拒绝文字修订         |
| 查找替换   | 普通文本查找、区分大小写、正则表达式和批量替换                 |
| 保存与导出 | 本地工作数据自动保存，导出 DOCX、HTML、TXT，通过打印生成 PDF   |
| 多人协作   | 显示在线人员、同步文档更新、提示并处理版本冲突                 |
| PDF 工具   | 阅读、缩放、标注、图片印章、行内文字修改和另存为 PDF           |
| 系统集成   | 通过 iframe 和 JavaScript SDK 嵌入，支持业务系统文档打开与回写 |
| 界面语言   | 支持中文、英文切换                                             |

### 1.2 使用方式

| 方式           | 使用入口                      | 保存结果                                       |
| -------------- | ----------------------------- | ---------------------------------------------- |
| 独立使用       | 访问部署站点的 `/editor.html` | 编辑器服务中的工作数据；需要长期留存时导出文件 |
| 业务系统内使用 | 从业务系统集成页面进入        | 自动保存草稿，正式保存后将 DOCX 回写业务系统   |

业务文档访问和写入权限仍需由业务系统及服务端控制。

## 2. 快速开始

### 2.1 打开编辑器

1. 编辑器预览地址：https://legaloffice.lenovo.com/editor.html
2. 从业务系统集成页面进入文档页面。

| 路径                    | 用途                     |
| ----------------------- | ------------------------ |
| `/`                     | 产品首页和演示           |
| `/editor.html`          | 独立编辑器               |
| `/embed-example.html`   | SDK 嵌入示例             |
| `/fullscreen-test.html` | 全屏持久化示例页面       |
| `/api-docs.html`        | 接口参考页面             |
| `/version`              | 查看当前服务包声明的版本 |
| `/api/health`           | 服务健康检查             |

编辑器依赖浏览器的现代网页能力。浏览器需要启用 JavaScript，并允许所需的文件下载、打印和网络请求。PDF 模块首次使用时会从外部 CDN 加载组件，受限网络环境需要管理员配置资源访问。

### 2.2 完成一次文档编辑

1. 选择“文件 → 新建”，或“文件 → 打开”选择已有 `.docx` 文件。
2. 点击顶部标题输入框，修改文档名称。
3. 点击正文区域输入文字，选中文字后使用工具栏设置格式。
4. 根据需要插入表格、图片、页码或批注。
5. 独立使用时，通过“文件 → 导出 → Word (.docx)”下载结果。
6. 业务系统集成使用时，点击“文件 → 保存”或按 `Ctrl+S`，等待保存完成后再离开。

自动保存草稿和业务系统正式保存是两个不同步骤，详见第 8 节。

## 4. 文档打开与管理

### 4.1 文件格式

| 格式             | 打开方式与支持范围                                                     | 输出方式                           |
| ---------------- | ---------------------------------------------------------------------- | ---------------------------------- |
| `.docx`          | 标准编辑入口；支持常用 Word 内容及部分复杂对象预览；支持源文件无损保存 | 导出 DOCX                          |
| `.txt`           | 作为纯文本导入编辑                                                     | 导出 TXT、HTML、DOCX，或打印为 PDF |
| `.html` / `.htm` | 导入经过安全清理的 HTML；不会完整运行原网页                            | 导出 HTML、TXT、DOCX，或打印为 PDF |
| `.pdf`           | 进入专用 PDF 界面，支持阅读与有限编辑                                  | 另存为新的 PDF                     |

### 4.2 新建、重命名与再次打开

- **新建**：选择“文件 → 新建”，创建空白文档。
- **重命名**：直接修改顶部标题，修改会进入自动保存流程。
- **再次打开**：选择“文件 → 文档库”，点击目标文档。
- **恢复上次文档**：独立编辑页面会尝试打开浏览器记录的上次文档，但前提是服务端工作数据仍然存在。
- **删除**：在文档库点击删除按钮并确认。删除后没有产品内回收站入口，请提前导出需要保留的内容。

## 5. 正文编辑与排版

### 5.1 文字和段落

选中文字后，可使用工具栏设置加粗、斜体、下划线、删除线、上标、下标、字体、字号、文字颜色和背景高亮。还可使用格式刷或清除格式。

段落支持正文、标题 1～6、引用、代码块，以及左对齐、居中、右对齐、两端对齐、缩进、行距、项目符号和编号列表。将光标放入段落后即可调整段落格式。

字号工具以磅（pt）显示。字体显示受当前设备已安装字体影响，换设备或导出后可能出现字体替换及换行差异。

### 5.2 查找与替换

1. 按 `Ctrl+F` 或点击查找替换按钮。
2. 输入查找内容，按需启用区分大小写或正则表达式。
3. 查看匹配结果，使用前后导航定位。
4. 输入替换内容，选择替换当前匹配或全部替换。

### 5.3 表格

1. 支持表格内容预览。
2. 编辑功能待优化。

### 5.4 图片、链接与其他对象

| 内容     | 操作方式                                   | 说明                                               |
| -------- | ------------------------------------------ | -------------------------------------------------- |
| 图片     | “插入 → 图片”，选择本地图片                | 插入时按可打印宽度缩放，选中后可使用可见控制点调整 |
| 超链接   | 选中文字后按 `Ctrl+K`，或选择“插入 → 链接” | 设置链接地址及显示文字，按ctrl + 鼠标左键访问      |
| 水平线   | “插入 → 水平线”                            | 插入正文分隔线                                     |
| 特殊符号 | “插入 → 符号”                              | 从符号面板选择                                     |
| 艺术字   | “插入 → 艺术字”                            | 输入文字并选择界面样式                             |
| 形状     | “插入 → 形状”                              | 选择矩形、箭头、星形等及填充颜色，可在页面中拖动   |

编辑器新建的艺术字、形状采用网页样式实现，其 DOCX 输出不等同于 Word 原生对象

从 DOCX 导入的原生复杂对象使用另一套保留机制，详见第 11 节。

### 5.5 页面、页眉页脚与页码

- **页面设置**：点击工具栏“页面设置”，选择 Letter、A4、Legal 或 A3，设置横向/纵向以及上下左右页边距。页边距按英寸输入，1 英寸等于 2.54 厘米。
- **分页**：在目标位置选择“插入 → 分页符”。
- **页眉/页脚**：选择“插入 → 页眉”或“页脚”，填写文字并设置左、中、右对齐；清空文字后应用可移除对应文字。
- **页码**：选择“插入 → 页码”，设置是否显示、数字样式以及页顶/页底的左、中、右位置。提供阿拉伯数字、罗马数字、字母和带总页数等样式。
- **缩放**：底部提供 75%、100%、125%、150% 显示比例；缩放用于阅读，不改变纸张尺寸。

## 6. 批注与修订审阅

### 6.1 添加和处理批注

1. 在正文中选中需要讨论的文字。
2. 点击工具栏批注按钮，或按 `Ctrl+Alt+M`。
3. 输入批注内容并提交。
4. 点击正文批注锚点或顶部“批注”，查看对应讨论。
5. 在批注卡片中回复、标记已解决、重新打开或删除批注。

添加批注需要非空文本选区。如果原锚点文字被移除，面板会提示批注无法定位。

### 6.2 记录和审核修订

1. 打开顶部“审阅”面板，勾选“修订”；也可按 `Ctrl+Shift+E` 切换。
2. 在开启状态下修改文字，插入和删除会显示为修订标记。
3. 审阅面板列出待处理的修改及作者等信息。
4. 对单条修改点击“接受”或“拒绝”，也可批量接受或拒绝全部修改。

接受插入会保留新增内容；拒绝插入会删除新增内容。接受删除会正式移除内容；拒绝删除会恢复内容。关闭修订开关不会自动清除已有待审修订。

### 6.3 撤销、重做和拼写检查

使用工具栏或快捷键撤销、重做当前编辑操作。

底部“拼写检查”调用浏览器原生功能，效果取决于浏览器语言和词典；产品没有提供独立语法审查、法律审查或自动纠错引擎。

## 7. 多人协作与历史版本

### 7.1 在线人员与同步

打开同一文档的人员会显示在顶部在线列表中。服务器通过实时连接通知其他客户端文档更新：

- 本地没有待保存修改时，可以自动应用远端更新。
- 本地存在未保存修改或正在保存时，会出现冲突提示。
- 连接中断会影响实时同步，应同时留意保存状态。

这套机制以整份文档的版本号检测冲突，不支持逐字符自动合并。多人修改同一段内容时，建议协调修改顺序。

### 7.2 处理冲突

| 按钮                 | 执行结果                                         | 适用情况               |
| -------------------- | ------------------------------------------------ | ---------------------- |
| 加载对方版本         | 以收到的远端版本替换当前内容，放弃本地待保存修改 | 确定采用对方修改       |
| 保留我的版本（覆盖） | 基于远端版本号重新提交本地内容，可能覆盖对方修改 | 已确认采用当前完整内容 |

发生冲突时，先核对需要保留的差异，必要时复制到其他位置，再选择处理方式。两个按钮都不会自动合并双方文字。

### 7.3 历史版本（暂时关闭）

服务端启用历史功能后，可点击顶部“历史”，选择快照并确认恢复。恢复前会尝试保留当前服务端版本的快照。

当前规则为：自动快照最小间隔约 90 秒，最多保留 10 份，保留时间不超过 3 天。并非每次输入或每次保存都生成新快照。

**仓库当前 Docker Compose 配置设置 `VERSION_HISTORY_ENABLED=false`，内部历史功能默认关闭。** 集成方还可通过 `history: false` 隐藏入口。业务系统自身的历史版本应通过业务系统查看。

## 8. 保存、导出与关闭

### 8.1 区分三种保存结果

| 操作                     | 独立使用                                                | 业务集成                               |
| ------------------------ | ------------------------------------------------------- | -------------------------------------- |
| 自动保存                 | 停止连续修改后约 1.2 秒触发，将工作数据保存到编辑器服务 | 同样只更新编辑器草稿                   |
| “文件 → 保存” / `Ctrl+S` | 完成编辑器工作数据保存，业务回写步骤跳过                | 先保存草稿，再生成 DOCX 并回写业务系统 |
| 导出                     | 下载文件到用户设备                                      | 下载副本，不代表已完成业务回写         |

定时业务回写有独立配置，默认关闭。

### 8.2 导出文档

从“文件 → 导出”选择：

- **Word (.docx)**：生成可由 Word 等软件打开的文件，并保留当前实现覆盖的格式、批注、修订和原始复杂对象信息。
- **Web 页面 (.html)**：导出文档 HTML，适合网页查看；不保证包含所有原始 DOCX 包部件。
- **纯文本 (.txt)**：输出文本，放弃字体、图片和表格外观等排版信息。
- **PDF（打印）**：打开浏览器打印对话框，选择“另存为 PDF”。这是文字文档的打印输出路径。

### 8.3 正确关闭

独立编辑器中的“文件 → 关闭文件”会先执行文档保存，再切换到空白文档。PDF 模式下该菜单直接关闭查看器，应先用 PDF 工具栏另存修改。

业务系统退出页面时，应由集成方等待 SDK `close()` 成功，再销毁编辑器或切换页面。直接关闭浏览器、刷新或异常退出时，浏览器只能尽力发起保存请求，不能保证最后一次修改回写完成。

### 8.4 工作数据保留

编辑器本地数据用于当前工作过程，正式业务文档以业务系统为准。当前实现与默认配置包括：

- 业务文档成功执行 SDK `close()`，并且最后一个实时连接离开后，可立即清理对应工作文件。
- 周期清理按不活跃时间处理业务工作数据，默认保留窗口为 24 小时；实际删除时间还取决于清理任务运行时间。
- 服务启动时默认清理草稿正文与历史，保留必要的生命周期元数据。这也意味着独立文档不能依赖工作目录获得长期保留保证。

需要长期保留的独立文档请导出到自己的存储位置；业务文档请完成正式回写。

## 9. PDF 阅读与操作（编辑功能待优化）

### 9.1 打开与浏览

选择“文件 → 打开”并选择 PDF。加载完成后会切换到专用工具栏，可翻页、放大缩小、适应屏幕、适应宽度及打印。还可使用 `Ctrl`/`⌘` 加滚轮缩放。

### 9.2 标注和修改

| 工具         | 操作与结果                                   |
| ------------ | -------------------------------------------- |
| 批注         | 选择批注工具后点击页面，添加备注             |
| 贴纸         | 添加签署位置提示、箭头、星标或勾选等视觉标记 |
| 图片印章     | 上传印章图片，放置到页面并调整位置或大小     |
| 签名         | 打开签名对话框，填写/绘制签名并放置          |
| 文字编辑     | 打开铅笔工具，在可提取的文本区域修改文字     |
| 保存为新 PDF | 点击 PDF 工具栏磁盘按钮，下载修改后的新文件  |

请使用 PDF 专用保存按钮，不要用 Word 文档菜单的“保存”代替。当前 PDF 路径在浏览器内操作并下载新文件，不提供与 Word 草稿相同的服务端自动保存、版本历史和业务回写流程。

### 9.3 PDF 能力边界

- **文字编辑**：通过提取文本并覆盖重绘实现，不提供扫描件 OCR，也不提供整页自动重排。当前输出使用内置西文字体，中文等字符或复杂原字体可能无法正确保存。
- **内容覆盖**：白色覆盖层并不等于从 PDF 中彻底删除原始文字，不能当作敏感内容脱敏功能使用。
- **标注输出**：标记会绘制进新 PDF，不能假定在其他阅读器中仍可作为标准批注对象独立编辑。
- **签名实现**：使用浏览器生成的 ECDSA 密钥，并嵌入 `signature.json` 元数据附件；当前未实现标准 PDF 证书签名流程，不能承诺外部 PDF 阅读器显示证书签名验证通过。
- **离线使用**：首次加载依赖外部 PDF 组件，不能默认视为完整离线产品。

## 11. Word 兼容范围

### 11.1 常规支持

DOCX 导入导出覆盖常用段落、文本样式、列表编号、表格与合并单元格、图片、链接、页面设置、批注及文字修订等。支持部分依赖 Word 样式定义的列表编号，以及页眉页脚文本和页码字段的解析与生成。

### 11.2 复杂对象保留

对嵌入对象、原生艺术字、部分形状、SmartArt、图表及公式等复杂内容，编辑器尽量显示只读预览或占位说明，并在导入及 DOCX 生成链路中保留原始 OOXML 和相关包部件。

这意味着对象可能在 Word 中继续存在，但在网页中只显示简化外观，且不能进行原生编辑。

对于含复杂对象的文件，应保留原件，在交付前打开导出的 DOCX 检查正文、表格、分页和对象显示。
