Embed DocEditor via iframe + JS SDK

The DocEditor SDK creates an iframe hosting the editor in another origin (or same-origin) and exposes the commands listed below over window.postMessage. Include <script src="http://editor-host/js/sdk.js"></script> then call DocEditor.init().

This reference is maintained manually against /js/sdk.js and the editor message handlers. It is not generated from source code.

Integration example (expand to view) 
// ─── bootstrap ───
const ed = DocEditor.init({
  container: "#editor-holder",  // CSS selector or Element
  baseUrl: "http://localhost:3001",
  user: "Alice",
  onReady(info)  { console.log("ready", info); },
  onDocument(info) { console.log("document", info); },
  onChange(info) { console.log("change", info); },
});

// ─── command methods return Promises; destroy() is synchronous ───
const meta  = await ed.getMeta();
const html  = (await ed.getContent()).html;
await ed.setContent("<p>Hello</p>");
await ed.bold(); await ed.justifyCenter();
await ed.insertImage("https://picsum.photos/360/200", { width:360, height:200 });
await ed.exportDoc("docx");
await ed.setPageSetup({ size:"A4", margins: { top:1, left:1 } });
const docs   = await ed.listDocuments();
await ed.newDocument("Memo");
await ed.addComment("Review this paragraph");
const { matches } = await ed.find("term", { matchCase:false, regex:false });
if (matches > 0) await ed.highlightSelection(); // temporary orange background / white text
await ed.clearHighlight();                     // restore the selection's original styles
await ed.close(); // wait for save before removing the iframe
ed.destroy();

Find / replace

SDK methodArgsReturns
findquery, {matchCase?, regex?}{matches}
highlightSelection—{ok:true}
clearHighlight—{ok:true}
replaceAllquery, replacement, {matchCase?, regex?}{replaced}
find() selects and reveals the first match without highlighting it. highlightSelection() temporarily paints the current selection orange with white text; repeated calls replace the previous SDK highlight. clearHighlight() removes only the SDK highlight and preserves the document's original formatting. Highlighting does not change saved/exported HTML or undo history.

Lifecycle

MethodDescription
destroySynchronously removes the iframe and message listener, and clears the pending-call map. Does not save or settle pending Promises. Await close() before destroying.
iframeThe underlying <iframe> element reference.
save() flushes the draft and performs business write-back for integrated documents. close() uses the same save flow with reason close; it does not remove the iframe. Both commands have a 60-second SDK timeout.

DocEditorRestClient — document operations over HTTP

DocEditorRestClient provides browser JavaScript helpers around the REST API. HTTP clients (curl, Python, Postman) can call the endpoints directly. Some SDK-like methods are local helpers, no-ops, or unsupported; see the capability notes below.

This reference is maintained manually against /js/api-client.js and server.js. The client does not attach authentication tokens; integrated documents require an authenticated HTTP request or the embed SDK.

Integration example (expand to view) 
// Load /js/api-client.js with a script tag before running this example.
// Browser usage
const api = new DocEditorRestClient("http://localhost:3001");

// Document management
await api.createDocument("My Document");
await api.loadDocument(docId);
const list = await api.listDocuments();
await api.deleteDocument(docId);

// Content
const content = await api.getContent();           // {html}
await api.setContent("<p>Hello</p>");
await api.insertHtml("<p>More</p>");
await api.insertText("plain text");
const meta = await api.getMeta();                 // {id, title, rev, words, chars, ...}
await api.setTitle("New Title");

// Formatting by HTML fragment
const bold = await api.formatHtml("bold", "text to embolden");  // {ok, html: "<strong>...</strong>"}
await api.bold("fragment");
await api.justifyCenter("<p>centered</p>");

// Page setup, headers, comments
await api.setPageSetup({ size: "A4", margins: { top: 1, bottom: 1 } });
await api.setHeader("Chapter 1", "right");
await api.addComment("Looks good!", "Alice");

// Export
await api.exportDoc("docx");   // downloads
await api.exportDoc("html");

// Versions
const versions = await api.listVersions();
await api.restoreVersion(0);
